# Gallery images

Drop pattern images in **this folder** (`src/assets/gallery/`). They are
discovered automatically at build time — no list to edit:

- the **Gallery** page shows all of them, sorted by filename;
- the landing page's "From the gallery" strip shows **3 picked at random** each visit.

The filename becomes the caption (`octa-xor.png` → "Octa Xor"), so name files
how you want them labelled. PNG, JPG, WebP, GIF, and AVIF are all picked up.
